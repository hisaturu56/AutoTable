# テーブル自動作成（AutoTable）

Illustrator で、キャラクター用の基礎ステータス表を自動で作成するスクリプトです。
動画（無限大ANANTA の解説動画など）で使う表を、文字と画像まで入れて PNG で書き出すところまで行います。

今のパネルのバージョン：**1.7.0**（2026-10-28 名前を「テーブル自動作成」に変えた）

## ふだんの使い方（流れ）

1. claude.ai で「このキャラのステータスをまとめて」などと頼むと、Claude が台本ページの中の「テーブルリスト」（Notion）に表のデータを書き込む（決まりは `Claudeへの説明_テーブルリスト.md`）
2. Illustrator のパネル「表を作る」タブ：台本が自動で選ばれる → 作る表にチェック → 割合（大きさ）を決めて「表を作る」（ラフと画像にする仕上げまで一緒にする）
3. 「調整」タブ：キャラ画像をまとめて入れる → 位置を 1 枚調整して「同じ表／チェックした表の画像を全部同じにする」 → 必要なら文字の大きさ
4. 大きさを変えたいときは、割合を変えて「表を作る」（作り直し。キャラ画像と調整は引き継ぐ）
5. 「書き出し」タブ：PNG で「素材」フォルダへ

## パネル（おすすめ）

Illustrator の「ウィンドウ」メニューから開いて、出しっぱなしにできるパネルです。上のタブ（表を作る・調整・書き出し）で 3 つの画面を切り替えます。設定はパネルの中に直接並んでいて、パネルを開いたまま Illustrator を操作できます。

| タブ | できること |
| --- | --- |
| 表を作る | データを **Notion** か **CSV** で選ぶ。**Notion**：開いているドキュメントに合う台本を自動で選び、台本ページの中の「テーブルリスト」の表を一覧にする（下の「Notion から作る」）。**CSV**：CSV を複数選んで一覧にする（× で一覧から外す）。どちらも、チェックした表をまとめて作る（1 つの表 ＝ 1 つのアートボード。キャラ欄は表ごとにチェックで変えられる）。位置と大きさ（幅・高さの割合はスライダーで 10〜100%。100%・50%・3分の2・3分の1・4分の3・4分の1 のボタンもある）・アートボード合わせ・作り直し（上書き）・**ラフをかける・画像にする**（最初からオン。表を作ったすぐあとに仕上げまでする）も設定して「表を作る」。設定はパネルを閉じても残る。**キャラ画像は表を作るときには入れない**（「調整」タブでまとめて入れる） |
| 調整 | 上の「対象の表」でチェックした表に**まとめて**操作する。**キャラ画像をまとめて入れる・変える…**（表ごとに画面が順に出る。行ごとに「選ぶ…」「なし」。Notion・CSV の「画像」に書いたファイル名が「素材」フォルダにあれば最初から入る予定。今の画像は「そのまま」なら調整した位置・大きさも残る。キャラ欄がない表・キャンセルした表・変えなかった表は、終わったあとに知らせる）。**文字の大きさ**（チェックした表の文字をまとめて同じ pt に）。**キャラ画像の位置**は 1 枚ずつ：画像を選び、拡大率・横・縦をスライダーか数値で調整、マスに合わせる・上ぞろえ・同じ表の画像を全部同じにする・チェックした表の画像を全部同じにする・画像を差し替える、画像なしのキャラ欄には「画像を入れる…」。Illustrator で画像をクリックしてからパネルに戻ると、その画像に切り替わる。元に戻すのは Ctrl+Z |
| 書き出し | 書き出すアートボードにチェックを入れて「PNG で書き出す」（最初は今のアートボードだけにチェック。全部選ぶ・全部外すあり）。「素材」フォルダへ、アートボード名のファイル名で保存 |

中の処理は、下のスクリプトと同じです（表を作るは `テーブル自動作成.jsx` をパネルの設定で実行、画像調整・書き出しは `panel/host.jsx` に同じ計算・書き出し方を入れてある）。

### 入れ方（おすすめ：ZXP UXP installer）

1. `AutoTable.zxp` をダウンロードする
2. ZXP UXP installer を開いて、`AutoTable.zxp` をドラッグ＆ドロップする（または「開く」から選ぶ）
3. Illustrator を再起動して、「ウィンドウ」→「エクステンション」→「テーブル自動作成」を開く

- 新しい `.zxp` が来たら、同じように入れれば上書きされる。消すときも ZXP UXP installer から
- **1.6.3 までの「ポロライドテーブル自動作成」（PolaroidTable）が入っているときは、ZXP UXP installer で先にそれを消す**（名前と ID を変えたので、別のパネルとして 2 つ並んでしまう）。Notion のトークンと、表を作るときの位置・大きさの値は、前のものをそのまま読むので入れ直さなくてよい。パネルの中の設定（データの選び方・チェックなど）は最初の状態に戻る
- `.zxp` には自己署名の証明書で署名している（`tools/SignZxp.java`。Adobe の ZXPSignCmd と同じ形式）。インストーラーで「発行元を確認できない」などの注意が出ても、そのまま進めてよい
- パネルが出ないときは、下の `install.bat` を 1 回実行する（署名なしのパネルを読み込む設定もするため）

### 入れ方（ZXP が使えないとき：install.bat）

1. `AutoTable_panel.zip` を展開する（右クリック →「すべて展開」）
2. 中の `install.bat` をダブルクリックする（「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」）
3. Illustrator を再起動する
4. 「ウィンドウ」→「エクステンション」→「テーブル自動作成」を開く

- スクリプトが新しくなったら、新しい zip で 1〜3 をやり直す（上書きされる）。1.6.3 までの古い名前のパネル（PolaroidTable）は install.bat が消す
- 消すときは `uninstall.bat` をダブルクリック
- `install.bat` は、署名していない手作りのパネルを Illustrator が読み込めるようにする設定（PlayerDebugMode）も一緒に行う
- `.zxp` と zip は `python3 tools/build_panel.py` で作る（`dist/AutoTable.zxp`・`dist/AutoTable_panel.zip`。Java 17 以降が必要）。中のスクリプトは `scripts/` のコピー

### Notion から作る

Premiere の「テロップ自動作成」と同じしくみです。

1. **トークンを登録（最初の 1 回）**：「表を作る」タブの「Notion の設定（トークン）」を開き、Premiere と同じコネクション「レターボックス_自動テロップ」のトークンを入れて「登録する」
   - Windows の暗号化（DPAPI）で `%APPDATA%\AutoTable\notion-token.dat` にしまう（同じ Windows ユーザーでしか元に戻せない）。画面には出さない
2. **台本を自動で選ぶ**：ドキュメント名と、配置した画像などのファイル名を台本DB のタイトルとくらべ、いちばん近い台本を選ぶ
   - 似ている度合い 50% 以上のうちで最も近いもの。ほぼ同じ近さ（差 5% 以内）なら公開日が今日に近いもの
   - 選んだ理由（どの名前で当たったか）が下に出る
3. **違ったら選び直す**：プルダウンは公開日が今日に近い順。手で選んだ台本は、そのファイルでは次からも選ばれる
4. **表の一覧**：台本ページの中の、名前に「テーブルリスト」を含むデータベースを読み、表ごとに一覧にする。チェックして「表を作る」
   - アートボード名（PNG のファイル名）は `台本タイトル_表の名前`。表の名前の頭の番号は 2 けたにそろえる（`1_基礎…` → `01_基礎…`。フォルダの中で 01、02 … の順に並ぶように）
   - 表のレイヤーは、アートボードの番号の順に上から並ぶ（01 の表がいちばん上。作り直しても同じ場所）
5. Notion のエラーは日本語で出る（トークン違い・コネクションがつながっていない・見つからない・混み合っている）

テーブルリストの形と作り方は `docs/Notionから表データを作る手順.md`。Claude に作ってもらうときの説明は `Claudeへの説明_テーブルリスト.md`（claude.ai の動画作りのプロジェクトの「ファイル」に入れる）。

## 使い方（スクリプトとして実行する場合）

1. `scripts/テーブル自動作成.jsx` を PC に保存する
2. Illustrator で「ファイル → スクリプト → その他のスクリプト…」からこのファイルを選ぶ
3. ダイアログで設定して OK

| 項目 | 内容 |
| --- | --- |
| CSVを選ぶ… | 表データを選ぶ。行数・列数はデータから自動で決まる。選ばなければ空の表を作る |
| 行数・列数 | CSV を使わないときだけ指定する（CSV を使うときは CSV から自動で決まる） |
| キャラ欄 | 左端にキャラ欄（正方形）を入れるか。CSV を選ぶと、1 列目が画像ファイルかどうかで自動でチェックが切り替わる。そのあと手で変えてもよい（外すと CSV の画像の列を使わずに作る。付けると CSV に画像の列がなくても空のキャラ欄を作り、画像は選ぶ画面で選ぶ） |
| 表全体の位置と大きさ | 下地（表全体）の X・Y（中心）・幅・高さ。初期値はアートボードの中心。前回入力した値を覚えている。「初期値に戻す」ボタンあり |
| 幅の割合・高さの割合 | プルダウンで「100%（そのまま）／67%（3分の2）／50%（半分）／33%（3分の1）」を選ぶと、入力した幅・高さにその割合をかけた大きさで作る（例：幅 1505 の 50% → 752.5）。作る大きさはすぐ下に表示される。中心の位置（X・Y）は変わらない |
| ラフ効果 | 手描き風のギザギザをかけるか |
| ラフを固定する | かけたラフを「アピアランスを分割」で普通の形に変える（スクリプト単体のときの設定。パネルでは「表を作る」タブの「ラフをかける」「画像にする」で、作ったすぐあとに仕上げる） |
| アートボードを表に合わせる | 作成後、アートボードを表（下地・ヘッダー・マス）にぴったりの大きさに変える。ラフのはみ出しも含め、整数の px にそろえる |

アクティブなアートボードの、ダイアログで指定した位置に表ができます。ドキュメントが開いていなければ 1920×1080 の RGB ドキュメントを新規作成します。

### キャラ画像の調整（`scripts/キャラ画像の調整.jsx`）

キャラ欄がある表の流れ：表を作る（このときは書き出さない）→ 調整画面で画像を調整・差し替えて OK → パネルの「PNG で書き出す」で完成した表を PNG で保存

表を作ったあとに実行すると、キャラ画像の拡大率と位置をスライダーで調整できます。動かすとその場で表に反映されます。

| 項目 | 内容 |
| --- | --- |
| アートボード | 調整する表のアートボードを選ぶ（キャラ画像がある表だけが出る。最初は選択中の画像か、今のアートボード） |
| 画像 | 選んだアートボードの画像を一覧から選ぶ（先にキャラ画像を選択してから実行すると、その画像が選ばれた状態で開く） |
| 拡大率（%） | 100% ＝ マスにちょうど隙間なく入る大きさ。100〜400% |
| 横・縦（px） | 0 ＝ 画像の中心がマスの中心。横は右、縦は下がプラス。数値を入れて Enter でも変えられる |
| マスに合わせる | 100%・中央に戻す |
| 上ぞろえに戻す | 画像の上端をマスの上端に合わせる（作ったときと同じ縦位置） |
| この画像を元に戻す | 調整画面を開く前の状態に戻す |
| 同じ表の画像を全部この画像と同じにする | 今の画像の拡大率・位置を、同じ表のほかのキャラ画像にも当てはめる（ロゴは対象外）。そのあと 1 枚ずつ微調整する |
| 画像を差し替える… | 選んでいる画像を別の画像に入れ替える（「素材」フォルダから開く）。切り抜きの枠はそのままで、マスいっぱい・上ぞろえに入る。名前も「行番号_ファイル名」に変わる |
| OK／キャンセル | OK で確定。キャンセルですべての画像を開く前の状態に戻す（差し替えた画像も元に戻る） |

切り抜きの枠（マスの形）は動かず、中の画像だけが動きます。

### 表の作り直し（上書き）

「同じ名前の表があれば作り直す（上書き）」にチェックを入れて「表を作る」を押すと、前の表を消して、同じ位置に作り直します（キャラ欄を入れ忘れたときなど）。

- CSV を使うとき：CSV と同じ名前のアートボードの表を作り直す。同じ名前の表がなければ、ふつうに新しく作る
- CSV を使わないとき：今のアートボードの表を作り直す（作り直したい表をクリックして、そのアートボードを選んでから押す）
- 位置（下地の中心）は前の表のまま。大きさ・キャラ欄などは、パネルの今の設定で作る
- 消す前に確認が出る（間違えたら Ctrl+Z）
- **入れたキャラ画像は引き継ぐ**：同じ行のキャラ欄に、新しいマスの大きさに合わせて縮小・移動する（マスの中での位置・拡大は同じ割合のまま）。キャラ欄がなくなった行の画像は消す
- **調整した文字の大きさも引き継ぐ**：自動で決まった大きさから変えた割合を、新しい表にもかける（1.6.2 より前に作った表は割合がわからないので、自動の大きさに戻る）
- 表を作ったあとに割合（大きさ）を変えたいときも、割合を変えて作り直せばよい
- このチェックは最初から入っている（外すと、同じ名前の表があっても新しいアートボードに作る）

### 2 つ目以降の表（アートボードを追加）

- アクティブなアートボードに何もなければ、そのアートボードに表を作る
- もう何か（1 つ目の表など）があれば、**最後のアートボードの右（100 px あけて）に、1920×1080 の新しいアートボードを追加**して、そこに表を作る
- 1 段に 3 つ並んだら（または右が Illustrator の作業できる範囲の外になるときは）、下の段の左はしに置く（`CONFIG.newArtboard.perRow`）
- 同じ .ai ファイルで続けて実行すれば、アートボード 1、2、3…と 1 表ずつ並ぶ

### 表の名前（アートボード名）

- アートボードの名前を、表の名前に自動で変える
  - CSV を使うとき：CSV のファイル名（例：`(テスト)表作成テスト用台本_1_基礎ステータス比較`）
  - CSV を使わないとき：`表1`、`表2`…（アートボードの番号）
  - 同じ名前のアートボードがあれば `名前 (2)` のように番号を付ける
- 表のレイヤー（下地・ヘッダー・テーブルをまとめた親レイヤー）も同じ名前にする
- PNG のファイル名もアートボード名になる。「ファイル → 書き出し → スクリーン用に書き出し」で書き出すときも、この名前が使われる

### PNG の保存先

- 「素材」フォルダは、キャラ画像を置く場所と同じ
- Illustrator ファイル（.ai）を保存してあれば、**同じ場所にある「素材」フォルダへ自動で保存**する（選ぶ画面は出ない）
  - 「素材」フォルダがなければ自動で作る
  - 同じ名前の PNG があるときは上書きしてよいか聞く。「いいえ」なら保存先を選ぶ画面を出す
- Illustrator ファイルを一度も保存していないときは、保存先を選ぶ画面を出す
- ファイル名はアートボード名（例：`(テスト)表作成テスト用台本_1_基礎ステータス比較.png`）。CSV を使わないときは `表1.png` など
- フォルダ名はスクリプト冒頭の `CONFIG.exportFolderName` で変更できる

```
（どこかのフォルダ）
├─ 動画の素材.ai      ← 表を作る Illustrator ファイル
└─ 素材
    └─ ○○.png        ← ここに自動で保存
```

メニューに常に出したい場合は、`.jsx` を次のフォルダに入れて Illustrator を再起動します。

```
C:\Program Files\Adobe\Adobe Illustrator（バージョン）\Presets\ja_JP\スクリプト
```

## CSV の形式

`samples/基礎ステータス_サンプル.csv` を参照（ほかの例は `samples/テスト用台本/`）。UTF-8 で保存します（Excel の「CSV UTF-8」形式で OK）。

```
images/無限大ロゴ.png,キャラクター,HP,攻撃力,防御力,エネルギー
images/タフィー.png,タフィー,3088,5088,4353,3618
images/タフィー.png,タフィー,9190,6838,5735,7132
```

- CSV の 1 行がそのまま表の 1 行になる。1 行目は項目名の行
- 1 列目が画像ファイルのパス（.png など。空欄も可）なら、キャラ欄ありの表になる。それ以外ならキャラ欄なし
- 画像は、ファイル名だけ書けば（例：`タフィー.png`）Illustrator ファイルと同じ場所の「素材」フォルダから探す
  - 探す順番：書いたパスそのまま → 「素材」フォルダ → CSV のあるフォルダ
  - `images/タフィー.png` のようにフォルダ名付きで書いても、「素材」フォルダの `タフィー.png` を見つける
  - Illustrator ファイルが未保存のときは「素材」フォルダの場所がわからないので、CSV のあるフォルダから探す
- キャラ画像は表を作るときには入れない。1 列目の画像のファイル名は、キャラ欄のマスのメモに残しておき、パネルの「調整」タブの「キャラ画像をまとめて入れる・変える…」を開いたときの初期値になる
- 入れた画像はマスいっぱいに拡大・縮小し、マスの形で切り抜く（上ぞろえ）。キャラごとに位置や大きさが違うので、入れた後に自分で調整する
  - キャラ画像は「キャラ画像」レイヤー（テーブルの上）にまとめて入る。名前は `行2_タフィー` のように「行番号_キャラ名」
  - 調整は `scripts/キャラ画像の調整.jsx` を使うと楽（下の「キャラ画像の調整」を参照）
- 1 行目（項目名の行）の画像（無限大ロゴ）は切り抜かずに、余白 15 px を空けてマスの中に収める
- 数字だけの値には 3 桁区切りのカンマを自動で付ける（3088 → 3,088）
- 文字はマスの中央に置く。フォントは文字が Noto Sans JP Black（40pt）、数字が Bahnschrift Bold（46pt）
- 文字の大きさは表全体でそろえ、マスの大きさに合わせる
  - 7 行まで（マスの高さ 約 71 px まで）は 40pt／46pt のまま（参考画像と同じ）。それより低いマスでは、高さに比例して小さくする
  - 一番長い文字がマスの幅に入りきらないときは、表全体の文字をまとめて縮める
  - 文字と数字は同じ割合で縮むので、バランスは変わらない
- 数字の縦位置は、カンマを除いた数字だけの形で中央に合わせる（カンマが下にはみ出す分、上に寄って見えないように）
- ヘッダーの帯の文字（CHARACTER BASE STATS）は AE でアニメーションさせるので、スクリプトでは入れない

## 表の仕様

ふつうは、表ごとに「表の名前」のレイヤーを作り、その中に 下地・ヘッダー・テーブル の 3 つのレイヤーを作って、ラフをかけます。

```
(テスト)表作成テスト用台本_1_基礎ステータス比較   ← 表の名前のレイヤー
├─ キャラ画像（キャラ欄の画像・ロゴ。ラフなし）
├─ テーブル（マス）
├─ ヘッダー
└─ 下地
```

一番上の階層に「テーブル」レイヤーがあり、その中に長方形があるときだけは、手で用意した表として扱います。その長方形をマス目に加工し、同じ階層の「下地」「ヘッダー」レイヤーがあれば、見た目をそのまま残して使います（アートボードは追加しない）。

### 位置と大きさ

ダイアログで下地（表全体）の X・Y・幅・高さを入力します（イラレの表示と同じ、基準点は中心）。
ヘッダーとテーブルは下地から自動で計算します。

- ヘッダー：下地の上フチから 7.5 px 下、左右 7.5 px 内側。高さ 30 px
- テーブル：ヘッダーの 7.5 px 下から、下地の下フチの 7.5 px 上まで。左右 7.5 px 内側

初期値は、下地の中心がアートボード（1920×1080）の中心に来る位置です。作ったあとに Illustrator で自由に動かしてかまいません。

| レイヤー | 幅 × 高さ | X | Y |
| --- | --- | --- | --- |
| 下地 | 1505 × 592.5 px | 960 | 540 |
| ヘッダー | 1490 × 30 px | 960 | 266.25 |
| テーブル | 1490 × 540 px | 960 | 558.75 |

### マス

- 下地のフチからヘッダー・テーブルまでの余白、マス同士の間隔はすべて 7.5 px
- 行の高さ = (テーブルの高さ − 7.5 ×（行数 − 1）) ÷ 行数（初期値の 540 px なら、3 行で 175 px、6 行で 83.75 px）
- キャラ欄は行の高さと同じ幅の正方形。残りの幅を列数で均等に分ける
- 1 マスは「テーブル」レイヤーの中の 1 グループ（長方形・文字）。レイヤーパネルでは 行1 が一番上で、行1_キャラ → 行1_列1 … 行2 … の順に並ぶ（キャラ画像レイヤーも 行1 が一番上）
- 新しく作るときの色：下地 #808080、ヘッダーとマス #303030、文字 #E0E0E0
- ラフは新しく作った下地・ヘッダーとマスにかける（文字と画像にはかけない）

サイズ・色・フォント・文字サイズはスクリプト冒頭の `CONFIG` で変更できます。
