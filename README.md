# PolaroidTable（ポロライドテーブル自動作成）

Illustrator で、キャラクター用の基礎ステータス表を自動で作成するスクリプトです。
動画（無限大ANANTA の解説動画など）で使う表を、文字と画像まで入れて PNG で書き出すところまで行います。

## 使い方

1. `scripts/ステータス表作成.jsx` を PC に保存する
2. Illustrator で「ファイル → スクリプト → その他のスクリプト…」からこのファイルを選ぶ
3. ダイアログで設定して OK

| 項目 | 内容 |
| --- | --- |
| CSVを選ぶ… | 表データを選ぶ。行数・列数はデータから自動で決まる。選ばなければ空の表を作る |
| 行数・列数 | CSV を使わないときだけ指定する |
| キャラ欄 | 左端に正方形のキャラ欄を入れるか |
| ヘッダーの文字 | ヘッダーの帯に入れる文字（初期値：CHARACTER BASE STATS） |
| ラフ効果 | 手描き風のギザギザをかけるか |
| PNG で書き出す | 作成後、表の部分だけを背景透過の PNG で保存する |

アクティブなアートボードの中央に表ができます。ドキュメントが開いていなければ 1920×1080 の RGB ドキュメントを新規作成します。

メニューに常に出したい場合は、`.jsx` を次のフォルダに入れて Illustrator を再起動します。

```
C:\Program Files\Adobe\Adobe Illustrator（バージョン）\Presets\ja_JP\スクリプト
```

## CSV の形式

`samples/基礎ステータス_サンプル.csv` を参照。UTF-8 で保存します（Excel の「CSV UTF-8」形式で OK）。

```
images/無限大ロゴ.png,キャラクター,HP,攻撃力,防御力,エネルギー
images/タフィー.png,タフィー,3088,5088,4353,3618
images/タフィー.png,タフィー,9190,6838,5735,7132
```

- CSV の 1 行がそのまま表の 1 行になる。1 行目は項目名の行
- キャラ欄ありのときは、1 列目が画像ファイルのパス（CSV からの相対パスか絶対パス。空欄なら画像なし）
- 画像はマスいっぱいに拡大・縮小し、マスの形で切り抜く（上ぞろえ）
- 数字だけの値には 3 桁区切りのカンマを自動で付ける（3088 → 3,088）
- 文字がマスに入りきらないときは、自動で文字サイズを縮める

## 表の仕様

開いているドキュメントに「テーブル」レイヤー（長方形が 1 つ）があれば、その長方形をマス目に加工します。
「ヘッダー」「下地」レイヤーもあればそのまま使い、ヘッダーの文字だけ追加します。
なければ 3 つのレイヤーを次の位置に新しく作ります（イラレの表示と同じ、基準点は中心）。

| レイヤー | 幅 × 高さ | X | Y |
| --- | --- | --- | --- |
| 下地 | 1505 × 592.5 px | 960 | 545 |
| ヘッダー | 1490 × 30 px | 960 | 271.25 |
| テーブル | 1490 × 540 px | 960 | 563.75 |

- 下地のフチからヘッダー・テーブルまでの余白、マス同士の間隔はすべて 7.5 px
- 行の高さ = (540 − 7.5 ×（行数 − 1）) ÷ 行数（3 行なら 175 px、6 行なら 83.75 px）
- キャラ欄は行の高さと同じ幅の正方形。残りの幅を列数で均等に分ける
- 1 マスは「テーブル」レイヤーの中の 1 グループ（長方形・画像・文字）
- 新しく作るときの色：下地 #808080、ヘッダーとマス #303030、文字 #D7D7D7

サイズ・色・フォント・文字サイズはスクリプト冒頭の `CONFIG` で変更できます。
フォントの初期値は Illustrator に付属する小塚ゴシック（`KozGoPr6N-Bold`）です。

## ファイル構成

```
scripts/ステータス表作成.jsx         表を作成するスクリプト
samples/基礎ステータス_サンプル.csv   CSV の例（数値はダミー）
tables/                               Notion から作った表データ（CSV）
docs/Notionから表データを作る手順.md  表の大きさの決め方と CSV の作り方
docs/計画.md                          今後の開発計画
docs/開発記録.md                      これまでの変更の記録
docs/手作業の作成手順メモ.txt         スクリプト化する前の手作業の手順（元の仕様）
```
