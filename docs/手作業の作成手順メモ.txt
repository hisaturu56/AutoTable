========================================================================
 📊 【イラレ】6×6 キャラクター用ステータス表作成手順（Windowsメモ用）
========================================================================
※動画編集（AE/Premiere）への個別レイヤー書き出しを前提としたマニュアル。

┌──────────────────────────────────────┐
│ ■ 1. 下地のベース作成（パーツを3つ作る）                             │
└──────────────────────────────────────┘
  長方形ツール [ M ] に切り替え、画面をクリックして以下3つのサイズを順に作成。

  ・① 外枠（一番下の下地・背景） ─── 幅 1500 px × 高さ 590 px
  ・② ヘッダー（上部のタイトル枠） ── 幅 1490 px × 高さ 30 px
  ・③ 表の本体（マス目になる枠） ─── 幅 1490 px × 高さ 545 px

┌──────────────────────────────────────┐
│ ■ 2. 位置合わせと微調整（5pxの余白ルール）                             │
└──────────────────────────────────────┘
  【整列】パネルを使い、外枠を基準にして上下に5pxの隙間を空ける。

  【① 外枠を画面の中央に置く】
    「1500×590の外枠」を選択 
     ➔ 【整列】パネル ➔ 整列対象：「アートボードに整列」
     ➔ 「水平方向中央揃え」＆「垂直方向中央揃え」をクリック

  【② ヘッダーを上フチから5px下に配置】
    1. 「1490×30のヘッダー」と「外枠」を [ Shift ] を押しながら両方選択
    2. そのまま「外枠」をもう1回クリック（キーオブジェクトに指定 ➔ 太線になる）
    3. 【整列】パネル ➔ 「水平方向中央揃え」 ➔ 「垂直方向上揃え」をクリック
       （※これで外枠の真上にピタッと吸着します）
    4. 選択を【ヘッダーだけ】にする
    5. [ Shift + Ctrl + M ] で【移動】ダイアログを開き、以下を入力してOK
       ├── 水平方向： 0 px
       └── 垂直方向： 5 px

  【③ 表の本体を下フチから5px上に配置】
    1. 「1490×545の表の本体」と「外枠」を [ Shift ] で両方選択
    2. そのまま「外枠」をもう1回クリック（キーオブジェクトに指定）
    3. 【整列】パネル ➔ 「水平方向中央揃え」 ➔ 「垂直方向下揃え」をクリック
       （※これで外枠の真下にピタッと吸着します）
    4. 選択を【本体だけ】にする
    5. [ Shift + Ctrl + M ] で【移動】ダイアログを開き、以下を入力してOK
       ├── 水平方向： 0 px
       └── 垂直方向： -5 px  ※上に上げるためマイナス

┌──────────────────────────────────────┐
│ ■ 3. レイヤー分けとロック（ミス防止）                                │
└──────────────────────────────────────┘
  ・【レイヤー】パネルで新規レイヤーを作成し、パーツを小分けにする。
  ・位置を決めた「外枠」と「ヘッダー」のレイヤーに「ロック（鍵マーク）」をかける。
  👉 ここからは、ロックしていない【表の本体（1490×545）】のみを加工！

┌──────────────────────────────────────┐
│ ■ 4. グリッド分割とサイズキープ（6×6マス）                           │
└──────────────────────────────────────┘
  1. ロックしていない「表の本体」を選択。
  2. [ Shift + G ] で【グリッドに分割】ダイアログを開く。
  3. 以下の数値を入力する。
     ├── 【行】の設定 ➔ 段数： 6  ／ 間隔： 5 px
     │    👉★超重要：このとき自動計算される高さ「 86.6667 px 」をコピー（ Ctrl + C ）！
     └── 【列】の設定 ➔ 段数： 6
  4. 「プレビュー」にチェックを入れ、先ほどコピーした高さ（86.6667 px）と
     完全に同じ数値になるよう、幅や間隔を調整して綺麗な正方形を作る。➔ [ OK ] で確定。

┌──────────────────────────────────────┐
│ ■ 5. 左端の基準枠とメインスペースの再分割                            │
└──────────────────────────────────────┘
  【① 左端に基準の正方形を密着させる】
    ・グリッド分割したマスのうち、「左上の正方形2つ」を同時選択。
    ・【整列】パネルの「等間隔に分布」の入力欄に「 0 px 」と入力。
    ・右横の「水平方向左側へ分布」をクリック ➔ 2つのマスが隙間なく密着。

  【② 左端のメイン枠の位置を確定】
    ・密着させた左端の縦一列（キャラクター用メイン枠）をすべて選択。
    ・[ Shift + Ctrl + M ] で【移動】ダイアログを開き、以下を入力してOK。
       ├── 水平方向： 5 px （右へ5px動かす）
       └── 垂直方向： 0 px
    ・重なって不要になった予備のマス（グレーの下地が見えている部分など）を削除。
    👉 すっきりした「左端1列（正方形） ＋ 右側に広い空きスペース」の状態にする。

  【③ 右側の空いたメインスペースをさらに「5列」に再分割】
    ・右側の広い空きスペース（白い長方形）を選択。
    ・再び [ Shift + G ] で【グリッドに分割】を開き、以下を入力してOK。
       ├── 【行】 段数： 6 ／ 間隔： 5 px （高さは 86.6667 px のまま維持）
       └── 【列】 段数： 5 ／ 間隔： 5 px

┌──────────────────────────────────────┐
│ ■ 6. 仕上げ加工（角丸とラフ効果）                                    │
└──────────────────────────────────────┘
  【① マス目の角を丸くする】
    ・ダイレクト選択ツール [ A ] に切り替える。
    ・中央の表のマス目をドラッグしてすべて選択。
    ・コントロールパネル（またはプロパティ）の「コーナー」の数値に「 15 px 」と入力 ➔ Enter。

  【② 全体にアナログな「ラフ」効果を適用】
    ・【レイヤー】パネルで「外枠」と「ヘッダー」のロック（鍵）を解除。
    ・選択ツール [ V ] で、画面上の【すべてのパーツ】をドラッグして全選択。
    ・上部メニュー：【効果】 ➔ 【パスの変形】 ➔ 【ラフ...】を開き、以下を入力。
       ├── サイズ： 1 px （※「入力値」にチェックを入れる）
       ├── 詳細 ： 100 /inch
       └── ポイント：「ギザギザ」にチェック
    ・数値を合わせて [ OK ] をクリック。

┌──────────────────────────────────────┐
│ ■ 7. 動画用レイヤー分配（最終工程）                                  │
└──────────────────────────────────────┘
  1. 【レイヤー】パネルで、大元の「テーブル」レイヤー（親レイヤー）を選択。
  2. パネル右上にある「オプションメニュー（三本線アイコン）」をクリック。
  3. メニューから【サブレイヤーに分配（シーケンス）】をクリック。
  
  ➔ 中のパスがすべて独立した個別の親レイヤーに格上げされたら、すべての作業が完了！
