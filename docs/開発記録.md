# 開発記録

## 2026-10-21

### 最初の版
- 手作業の手順メモ（`手作業の作成手順メモ.txt`）をもとに、外枠・ヘッダー・6×6 のマス目を作るスクリプトを作成
- 動画用に 1 パーツ 1 レイヤーで出力（手順メモの「サブレイヤーに分配」に相当）

### 完成画像に合わせて修正
- 実際に手作業で作った表の画像（3〜7 行）と比べて、次の点を修正
  - 左右に余計な 5 px の余白を入れていたのをなくし、外枠からの余白を上下左右とも 5 px に統一
  - 色を外枠 #808080、ヘッダーとマス #303030 に変更
  - 完成形に角丸がなかったため、角丸を 0 に変更（`cornerRadius` で変更可）
- 行数が表ごとに変わるため、実行時のダイアログで行数・列数・キャラ欄の有無を選べるようにした
- キャラ欄は行の高さに合わせて毎回正方形になるように計算
- キャラ欄なしの場合は、ステータス欄が表の幅いっぱいに広がる

### ラフ効果のオン・オフ
- ダイアログにラフ効果をかけるかどうかのチェックボックスを追加
- ラフ効果は Adobe の公式ドキュメントに設定方法が載っていない方法でかけているため、
  実機で効くかは未確認。効かなければ「効果 → パスの変形 → ラフ」を手動でかける

### 方針の決定
- 文字は AE ではなく Illustrator で入れて、PNG 画像 1 枚として書き出す
- 表の中身は Notion のキャラDB・台本DB から Claude が読み取る
- 詳しくは `計画.md` を参照
