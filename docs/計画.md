# 開発計画

## ゴール

文字入りのステータス表を Illustrator だけで完成させ、PNG 画像 1 枚として書き出す。

これまで文字は After Effects（エッセンシャルグラフィックス）で入れていたが、
Notion の情報から Claude が中身を作り、Illustrator で流し込む形に切り替える。
AE でのアニメーションは画像に対してのみ付ける想定で、優先度は低い。

## 全体の流れ

```
Notion（キャラDB・台本DB）
   ↓ Claude が読み取って表データ（CSV）を作成 → 内容を確認
Illustrator：スクリプトで表を作成 → 文字を流し込む →（キャラ画像を配置）
   ↓
PNG で書き出し
```

## ステップ

### 1. 表の作成スクリプトを仕上げる（進行中）
- [x] 外枠・ヘッダー・マス目の作成
- [x] 行数・列数・キャラ欄の有無をダイアログで選択
- [x] ラフ効果のオン・オフ
- [x] 表全体の位置と大きさをダイアログで指定（7.5 px の余白・間隔と、キャラ欄の正方形は保つ）
- [ ] 実際の Illustrator で動作確認（サイズ・位置・色・ラフ効果）

### 2. 表データの形を決める
- [x] 表の並べ方：1 行目が項目名、2 行目以降が 1 行 = 1 キャラ（参考画像より）
- [x] 列：キャラ画像／キャラクター／HP／攻撃力／防御力／エネルギー
- [x] 表データ（CSV）の形式を決める（README 参照）

### 3. 文字の流し込み
- [x] CSV を読み込み、行数・列数をデータから自動で決める
- [x] 文字をマスの中央に配置、数字に 3 桁区切りのカンマ
- [x] フォント・文字サイズを本番の指定に合わせる（Noto Sans JP Black / Bahnschrift Bold）
- [x] ヘッダーの帯の文字は入れない（AE でアニメーションさせるため）

### 4. キャラ画像の配置
- [x] CSV に書いた画像をキャラ欄の正方形に合わせて配置
- [x] 素材フォルダの場所：Illustrator ファイルと同じ場所の「素材」フォルダ（キャラ画像を置き、書き出した PNG もここへ）
- [ ] 画像のファイル名のルールを決める
- [x] キャラ画像は毎回変わるので、位置は覚えずに自分で調整する。行ごとに画像を選ぶ画面を出し、マスの形で切り抜いて入れる
- [x] ロゴ（1 行目）は切り抜かずにマスの中に収める
- [x] キャラ画像を「キャラ画像」レイヤーに分ける
- [x] キャラ画像の拡大率と位置をスライダーで調整するスクリプト（`キャラ画像の調整.jsx`）
- [x] 画像の差し替え、調整が終わってから PNG を書き出す（「OKして書き出す」）

### 5. 画像の書き出し
- [x] 表の部分だけを背景透過の PNG で書き出し
- [x] アートボードを表にぴったり合わせてから書き出す（ラフのはみ出しも含む）
- [x] Illustrator ファイルと同じ場所の「素材」フォルダへ自動で保存（なければ作る。未保存なら保存先を選ぶ）
- [x] 2 つ目以降の表は新しいアートボードに作り、アートボード名を表の名前にする（PNG のファイル名にもなる）

### 6. Notion から CSV を作る
- [x] キャラDB・台本から Claude が CSV を作る手順を決める（`Notionから表データを作る手順.md`）
- [x] 表の大きさ（何行 × 何列）は Claude が台本とステータスから判断する
- [ ] エネルギーの値の取り先を決める（キャラDB にまだ項目がない）

### 7. Notion から直接読み込む（後回し・ローカルで）
- [ ] Notion API で台本・キャラDB を直接読み、表データを作る方式にする（Claude を通さない）
  - 作業はローカル（自分の PC）で行う予定
  - Notion のインテグレーション（API キー）の用意が必要。キーはリポジトリに入れない
  - 今の「Claude が台本を読んで CSV を作る」方式は、それまでそのまま使う

### 8. パネル化
- [x] CEP パネルを作成（ボタンで今のスクリプトを実行する）。install.bat で入れる
- [ ] 実機で動作確認
- [ ] 必要なら、ダイアログの中身をパネルの中に移す

## Notion の構成（参考）

「無限大ANANTA」ページの中にある次の DB を使う想定。

- **キャラDB**：名前・レアリティ・属性・武器種・ロール・最大HP・攻撃力・防御力・実装日・画像
- **台本DB**：解説動画などの台本。「基本ステータス」などの章がある
- **キャラ台本セット用DB**：キャラと台本を紐づける

読み取り方の方針：
- 数値はキャラDBから取る（台本の文章より正確なため）
- 台本は「どのキャラを表に出すか」を決めるのに使う
- 技の数値など DB にない情報は台本から拾う
- ステータスは未確定なので、数値はスクリプトに固定で書かず、毎回 Notion から読み直す
- 空欄の項目は「未定」などの仮表記にする
