# 開発計画

## ゴール

文字入りのステータス表を Illustrator だけで完成させ、PNG 画像 1 枚として書き出す。

これまで文字は After Effects（エッセンシャルグラフィックス）で入れていたが、
Notion の情報から Claude が中身を作り、Illustrator で流し込む形に切り替える。
AE でのアニメーションは画像に対してのみ付ける想定で、優先度は低い。

## 全体の流れ

```
Notion（キャラDB・台本DB）
   ↓ Claude が読み取って表データ（CSV）を作成 → 内容を確認
Illustrator：スクリプトで表を作成 → 文字を流し込む →（キャラ画像を配置）
   ↓
PNG で書き出し
```

## ステップ

### 1. 表の作成スクリプトを仕上げる（進行中）
- [x] 外枠・ヘッダー・マス目の作成
- [x] 行数・列数・キャラ欄の有無をダイアログで選択
- [x] ラフ効果のオン・オフ
- [ ] 実際の Illustrator で動作確認（サイズ・位置・色・ラフ効果）

### 2. 表データの形を決める
- [x] 表の並べ方：1 行目が項目名、2 行目以降が 1 行 = 1 キャラ（参考画像より）
- [x] 列：キャラ画像／キャラクター／HP／攻撃力／防御力／エネルギー
- [x] 表データ（CSV）の形式を決める（README 参照）

### 3. 文字の流し込み
- [x] CSV を読み込み、行数・列数をデータから自動で決める
- [x] 文字をマスの中央に配置、数字に 3 桁区切りのカンマ
- [x] ヘッダーにタイトル文字を入れる
- [ ] フォント・文字サイズを本番の指定に合わせる

### 4. キャラ画像の配置
- [x] CSV に書いた画像をキャラ欄の正方形に合わせて配置
- [ ] 素材フォルダの場所とファイル名のルールを決める

### 5. 画像の書き出し
- [x] 表の部分だけを背景透過の PNG で書き出し

### 6. Notion から CSV を作る
- [ ] キャラDB・台本から Claude が CSV を作る手順を決める
- [ ] エネルギーの値の取り先を決める（キャラDB にまだ項目がない）

### 7. パネル化（必要になったら）
- 機能が増えてダイアログで扱いにくくなったら、CEP または UXP のパネルにする

## Notion の構成（参考）

「無限大ANANTA」ページの中にある次の DB を使う想定。

- **キャラDB**：名前・レアリティ・属性・武器種・ロール・最大HP・攻撃力・防御力・実装日・画像
- **台本DB**：解説動画などの台本。「基本ステータス」などの章がある
- **キャラ台本セット用DB**：キャラと台本を紐づける

読み取り方の方針：
- 数値はキャラDBから取る（台本の文章より正確なため）
- 台本は「どのキャラを表に出すか」を決めるのに使う
- 技の数値など DB にない情報は台本から拾う
- ステータスは未確定なので、数値はスクリプトに固定で書かず、毎回 Notion から読み直す
- 空欄の項目は「未定」などの仮表記にする
